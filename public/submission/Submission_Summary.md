# Campus Build Race — submission package

Updated 5 October 2026. A live, mobile-first workshop registration product with a college race, a personal Build Card, referrals and a protected growth desk.

## The four requested submissions

1. **Growth Plan — five slides:** [Growth_Plan.pdf](https://campus-build-race-nxtwave.vabjashwanthreddy.chatgpt.site/submission/Growth_Plan.pdf). Target: 500 registrations in seven days with a proposed ₹2,000 budget. Includes channel math, daily targets, a day-four decision gate, measurement and risks. This is a forecast, not an acquired-student claim.
2. **Working Asset — live product:** [Campus Build Race](https://campus-build-race-nxtwave.vabjashwanthreddy.chatgpt.site). Demonstrate the campus page → choose branch → choose interest → see Build Card → consented registration → referral/share kit. Registrations persist in a hosted D1 database. Fictional demonstration records are labelled.
3. **AI + Learning Notes — three examples:** [AI_Learning_Notes.pdf](https://campus-build-race-nxtwave.vabjashwanthreddy.chatgpt.site/submission/AI_Learning_Notes.pdf). Each records what was asked, what AI suggested and what changed: durable database fallback, withholding unknown event details and rejecting the original visual direction.
4. **Under-three-minute video — 2:55:** [Campus_Build_Race_Demo.mp4](https://campus-build-race-nxtwave.vabjashwanthreddy.chatgpt.site/submission/Campus_Build_Race_Demo.mp4). Explains the approach, plan, real hosted product and learning. Narration is clearly labelled synthetic. [Video_Script.md](https://campus-build-race-nxtwave.vabjashwanthreddy.chatgpt.site/submission/Video_Script.md) supports recording the applicant's own voice, which the original brief requests.
